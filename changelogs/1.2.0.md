# Seven versions, two new loaders

- Now on 26.2, 26.1, 1.21.11, 1.21.1 and 1.20.1 (Fabric), plus 1.21.1 (NeoForge) and 1.20.1 (Forge).
- One shared source tree, one balance table — the same numbers on every version.
- Every node works on every version. Omni Block, Instinctive Guard, Immovable Object, Unstoppable Force and Gliding all run on 1.21.1 and 1.20.1 too, rebuilt against those versions' own shield and elytra code rather than approximated.
- Tree screen and picker now hold their layout at every GUI scale. Node size, spacing and icons are derived from the panel, so nodes no longer sit tiny in a huge window at low scale, and node icons no longer disappear at high scale.
- Existing worlds and saved trees are untouched.

Balance and fixes, all versions:

- Ice Blast: direct hits now deal their damage (was area-only); blast area 3x3 → 4x4.
- Fireball: blast area 3x3 → 4x4; direct hits connect reliably.
- Vaporize reworked: a fireball clears water across its own 4x4 blast; flamethrower bolts boil exactly 1 block and expire. Flame bolts now die at 16 blocks or 2 seconds — no more stuck bolts piling up in water.
- Long Watch: Deadeye lasts 45 seconds, up from 25.
- Protector's "Bulwark" renamed to "Omni Block" — the name collided with Colossus-Crusher's Bulwark.
- Resetting a tree now clears Well Fed's banked hunger instead of leaving it above the bar.
- Titan's Leap description no longer promises a damage-free landing.

Feature differences on the older versions, listed so nothing is a surprise:

- ESP wall-piercing is 26.2 only. Marked targets still outline; the outline no longer shows through walls on any other version.
- Unstoppable Force is unarmed-only on 1.20.1 (both loaders) — no mace exists there. Its description says so on those versions.
- Instinctive Guard soaks lightning on 1.21.1 and 1.20.1 (both loaders); on 26.2/26.1/1.21.11 lightning bypasses shields entirely. That is each version's own shield behaviour, not a mod difference.
- No custom animations on 1.20.1 (both loaders): dagger stab, bladestorm, decimate, decimate charge, quake charge, shield sweep, dark ritual, flame channel. Cosmetic only — vanilla arm swing stands in, and no cooldown, cost or damage changes.
- 1.20.1 Forge and 1.20.1 Fabric do not share world data. Archetype, level and node data written by one is not read by the other.

Skill Proficiencies interop works on all seven, including both loader versions.
