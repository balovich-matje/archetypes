# Tag-driven weapons for modpacks

- Every weapon check is now an item tag packs can extend (GitHub #3). New: `#archetypes:swords`, `#archetypes:maces`, `#archetypes:bows`, `#archetypes:crossbows`, `#archetypes:shields`, `#archetypes:combat_weapons`, `#archetypes:milk`. Existing and now documented: `#archetypes:greatswords` (Decimate), `#archetypes:daggers`, `#archetypes:wands`, `#archetypes:meat`, `#archetypes:fruit`.
- Mace abilities (Quake, Meteor, Shockwave, Unstoppable Force, Titan's Leap) read `#archetypes:maces` instead of the vanilla mace only.
- Defaults hold the vanilla items plus matching convention tags (`c:` / `forge:`), so vanilla behaviour is unchanged on every version.
- Datapack example and full tag list: README, "Modpack / mod compatibility". On 1.20.1 the folder is `tags/items/`.
- 1.20.1: F1 keeps the Sun Blind and Deadeye screen washes, like vanilla's pumpkin and vignette on that version; the bars still hide.
- Inventory tab re-positions every frame — no longer left behind when the recipe book opens
