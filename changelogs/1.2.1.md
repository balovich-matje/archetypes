# Progress-loss fix for 1.20.1 Forge

- 1.20.1 Forge: tree state is re-sent to the client after a dimension change, a respawn and a gamemode change. Fixes progress appearing voided after entering another dimension (GitHub #2) — the server never lost it, the client was reading an empty tree until you relogged.
- The server now refuses a stale archetype re-pick and re-syncs instead, so a desynced client can no longer overwrite an archetype it cannot see.
- The tree screen shows a brief waiting note until the first sync arrives, instead of offering the archetype picker.
- Other versions are unaffected by the 1.20.1 Forge sync change.
